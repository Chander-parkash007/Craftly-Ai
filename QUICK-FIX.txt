Your app works, but AI features (material detection & craft 
generation) are using fallback data instead of real AI.


┌──────────────────────────────────────────────────────────────┐
│  ✅ THE FIX (5 Minutes)                                       │
└──────────────────────────────────────────────────────────────┘

STEP 1: Get Free API Key
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Open browser → https://console.groq.com
  2. Sign up (FREE, no credit card)
  3. Click "API Keys" → "Create API Key"
  4. Copy the key (starts with "gsk_")


STEP 2: Add Key to .env File
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Open the ".env" file in this folder
  2. Find: REACT_APP_GROQ_API_KEY=paste_your_groq_key_here
  3. Replace with: REACT_APP_GROQ_API_KEY=gsk_your_key_here
  4. Save the file


STEP 3: Restart App
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. In terminal: Press Ctrl + C
  2. Type: npm start
  3. Press Enter


STEP 4: Verify It Works
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. In browser: Press F12
  2. Look for: "Groq key loaded: YES"
  3. Upload image → Should detect real materials
  4. Generate crafts → Should see unique ideas

└──────────────────────────────────────────────────────────────┘

Problem: Can't find .env file
Solution: It's in the same folder as package.json
          Enable "Show hidden files" in Windows

Problem: Changes not working
Solution: Make sure you saved the file
          Restart the app completely
          Clear browser cache (Ctrl+Shift+Delete)

Problem: Still shows "NO - KEY MISSING"
Solution: Check the key starts with "gsk_"
          No extra spaces before/after the key
          File is named exactly ".env"
